### ENV
По дефолту рассматривай так, будто мы в dev окружении

### Project tree structure
/devops -- папка с докером которая подготавливает к запуску проект и его сервисы
/code -- список сервисов проекта
/code/api -- сервис бекэнда
/code/app -- сервис фронтэнда

/devops/docker/local/docker-compose.yaml -- если нужно, можешь сюда глянуть для лучшего понимания

### Backend tree structure
tests/requests -- реквесты для тест кейсов
tests/response -- ответы для проверки в тест кейсах
src/ -- основные классы приложения и бизнес логики
config/packages -- роутеры консоль и подвязка событий с слушателями
config/services.yaml -- сервисы
migrations/ -- миграции
src/Contracts -- папка с интерфейсами. Пример src/Contracts/Repository/UserRepositoryInterface.php

#ребования при написании кода
Стремимся к clean архитектуре
Типичная связка Controler/Command -> UseCase -> Service -> Repository/RequestService
Избегать написание комментариев
